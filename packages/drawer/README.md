# Drawer

抽屉。经 `@vapor-component/portal` 挂载，支持四种 `placement`、遮罩、过渡、嵌套推挤（`push`）、焦点锁定与拖拽调整尺寸（`resizable`）。内容一律走默认插槽，本包两侧均无 `VueNode` 类型 prop。

## Props

`DrawerProps = Omit<DrawerPopupProps, 'prefixCls' | 'inline'>` + 下列自有字段。`inline` 由 `getContainer === false` 推导。六个鼠标/键盘事件与 `afterOpenChange` 都不在 props 类型里，改由 `defineEmits` 暴露（见 Events 表）—— 监听一律用 `@mouseenter` 等小写事件 / `@after-open-change` 或 `@afterOpenChange`。

| 名称                   | 类型                                                                                                     | 默认值        | 说明                                                                                                                                                                                                            |
| ---------------------- | -------------------------------------------------------------------------------------------------------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| prefixCls              | `string`                                                                                                 | `'vc-drawer'` | 样式类前缀；Popup 内部再兜底一次                                                                                                                                                                                |
| open                   | `boolean`                                                                                                | —             | 是否打开（受控）。内部 `mergedOpen = shallowRef(!!open)` 并 `watch` 同步，但**传给 Popup 的是原始 `open`**（见「与 @v-c 差异」）                                                                                |
| placement              | `Placement`                                                                                              | `'right'`     | `'left' \| 'top' \| 'right' \| 'bottom'`；根节点类名 `-{prefix}-{placement}`，同时决定 `width` / `height` 走哪一条                                                                                              |
| push                   | `boolean \| PushConfig`                                                                                  | —             | 嵌套抽屉推挤。`PushConfig = { distance?: number \| string }`；`true` 用默认距离 **180**，`false` 强制 `distance: 0`                                                                                             |
| forceRender            | `boolean`                                                                                                | —             | 首次即挂载 DOM：`animatedVisible` 初值为 `!!(forceRender \|\| open)`，且跳过 `destroyOnHidden` 的空渲染分支                                                                                                     |
| autoFocus              | `boolean`                                                                                                | `true`        | 打开后 `nextTick` 聚焦面板容器（`flush: 'post'`）                                                                                                                                                               |
| focusTrap              | `boolean`                                                                                                | —             | 焦点锁定。缺省时取 `mask !== false`，即**默认开启**                                                                                                                                                             |
| keyboard               | `boolean`                                                                                                | `true`        | 按 Esc 关闭。经 Portal 的 `onEsc`，且仅在最顶层（`top`）生效                                                                                                                                                    |
| mask                   | `boolean`                                                                                                | `true`        | 是否渲染遮罩。传给 Popup 的是 `mask !== false`                                                                                                                                                                  |
| maskClosable           | `boolean`                                                                                                | `true`        | 点击遮罩关闭（`maskClosable && open` 才触发）                                                                                                                                                                   |
| destroyOnHidden        | `boolean`                                                                                                | `false`       | 关闭后销毁 DOM。仅当 `!forceRender && !animatedVisible && !open && destroyOnHidden` 全部成立时才返回空节点                                                                                                      |
| getContainer           | `any`                                                                                                    | —             | Portal 挂载容器；`=== false` 时转为 `inline`（本包内渲染，不 createPortal）                                                                                                                                     |
| focusTriggerAfterClose | `boolean`                                                                                                | `true`        | 关闭后把焦点还给打开前的元素（`document.activeElement`）；@v-c 语义是「不传 = 开启」。默认 `true` 已进 `withDefaults`（不写的话 vapor 会把缺省的可选布尔 cast 成 `false`，守卫 `!== false` 恒不成立，见差异表） |
| panelRef               | `any`                                                                                                    | —             | 面板元素回调，支持函数 ref 或 `{ value }` ref 两种形式                                                                                                                                                          |
| wrapperClassName       | `string`                                                                                                 | —             | **已废弃**，dev 环境 warning 提示改用 `rootClassName`；运行时不生效                                                                                                                                             |
| rootClassName          | `string`                                                                                                 | —             | 根节点额外类名                                                                                                                                                                                                  |
| rootStyle              | `CSSProperties`                                                                                          | —             | 根节点内联样式，与 `zIndex` 合并（`zIndex` 覆盖）                                                                                                                                                               |
| zIndex                 | `number`                                                                                                 | —             | 根节点 `z-index`                                                                                                                                                                                                |
| width                  | `number \| string`                                                                                       | —             | 水平方向宽度，`size` 缺省时的回退                                                                                                                                                                               |
| height                 | `number \| string`                                                                                       | —             | 垂直方向高度，`size` 缺省时的回退                                                                                                                                                                               |
| size                   | `number \| string`                                                                                       | —             | 尺寸，优先级高于 `width` / `height`。`parseWidthHeight` 会剥掉 `px` 后缀并 warning                                                                                                                              |
| maxSize                | `number`                                                                                                 | —             | 拖拽尺寸上限，**需 `> 0` 才生效**（下界恒为 0）                                                                                                                                                                 |
| defaultSize            | `number \| string`                                                                                       | —             | 非受控拖拽的初始尺寸；优先级低于 `currentSize`                                                                                                                                                                  |
| resizable              | `boolean \| { onResize?: (size: number) => void; onResizeStart?: (size: number) => void; onResizeEnd?: (size: number) => void }` | —             | 拖拽调整尺寸。`mergedSize` 优先级：`size` > `width` \| `height` > `currentSize` > `defaultSize` > `378`（仅水平方向，垂直为 `undefined`）                                                                       |
| motion                 | `CSSMotionProps \| ((placement: Placement \| undefined) => CSSMotionProps)`                              | —             | 面板过渡；`getTransitionProps(motion?.name, motion)` 转换后交给 `<Transition>`                                                                                                                                  |
| maskMotion             | `CSSMotionProps`                                                                                         | —             | 遮罩过渡                                                                                                                                                                                                        |
| maskClassName          | `string`                                                                                                 | —             | 遮罩额外类名                                                                                                                                                                                                    |
| maskStyle              | `CSSProperties`                                                                                          | —             | 遮罩内联样式                                                                                                                                                                                                    |
| id                     | `string`                                                                                                 | —             | 面板（`-section`）的 `id`                                                                                                                                                                                       |
| classNames             | `DrawerClassNames`                                                                                       | —             | 语义化类名，见下节                                                                                                                                                                                              |
| styles                 | `DrawerStyles`                                                                                           | —             | 语义化样式，见下节。@v-c 的 `drawerRender` 渲染函数在本仓改为同名 slot，见下节与「与 @v-c 差异」                                                                                                                |

## Events

| 名称              | 参数                                | 说明                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| close             | `(e?: MouseEvent \| KeyboardEvent)` | 关闭：遮罩点击（`maskClosable`）或 Esc（`keyboard` 且最顶层）。两条路径分别携带 `MouseEvent` / `KeyboardEvent`                                                                                                                                                                                                                                                                 |
| after-open-change | `(open: boolean)`                   | 面板过渡结束后触发（`@afterEnter` / `@afterLeave`），同时驱动 `animatedVisible` 在 `nextTick` 清理，配合 `destroyOnHidden` 卸载 DOM。emits 名是 `afterOpenChange`，监听写 `@after-open-change` 或 `@afterOpenChange` 均可（vapor 编译会做 camelize）。**不要写成 prop**（`:afterOpenChange="fn"` 或 `:onAfterOpenChange="fn"`）：字段已从 props 类型移除，写成 prop 会静默无效 |
| mouse-enter       | `(e: MouseEvent)`                   | 面板上 mouseenter，经 Panel → Popup → Drawer 逐级 `emit` 转发（`@mouseenter` 小写监听；emits 名同为 `mouseenter`）                                                                                                                                                                                                                                                             |
| mouse-over        | `(e: MouseEvent)`                   | 同上                                                                                                                                                                                                                                                                                                                                                                           |
| mouse-leave       | `(e: MouseEvent)`                   | 同上                                                                                                                                                                                                                                                                                                                                                                           |
| click             | `(e: MouseEvent)`                   | 同上                                                                                                                                                                                                                                                                                                                                                                           |
| keydown           | `(e: KeyboardEvent)`                | 同上                                                                                                                                                                                                                                                                                                                                                                           |
| keyup             | `(e: KeyboardEvent)`                | 同上（Enter 不在本包内做关闭，Esc 走 Portal 的 `onEsc`）                                                                                                                                                                                                                                                                                                                       |

## Slots

| 名称         | 作用域 | 说明                                                                                                                 |
| ------------ | ------ | -------------------------------------------------------------------------------------------------------------------- |
| default      | —      | 抽屉内容，经 `DrawerPopup` 的 `<slot />` → `DrawerPanel` 的 `<slot />` 落到 `-{prefix}-section` 节点内               |
| drawerRender | —      | 整个面板的自定义渲染。@v-c 的 `drawerRender(node) => node` 渲染函数在此改为同名 slot，默认内容仍是标准面板，见差异表 |

## Expose

| 名称     | 类型                                      | 说明                                                                                                                                                                                                                                                    |
| -------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| panel    | `ShallowRef<HTMLDivElement \| undefined>` | `-section` 面板节点引用，由 `DrawerPanel` 经 `setPanel` 上报                                                                                                                                                                                            |
| popupRef | `ShallowRef<any>`                         | `DrawerPopup` 实例引用。Popup `defineExpose({ panelRef })`（与 @v-c 一致），vapor 读 expose 会解包 ref —— `popupRef.value.panelRef` 拿到的是容器**元素本身**，所以本包内（及使用方）取值都写 `popupRef.value?.panelRef`（不是 @v-c 的 `?.panelRef?.value`） |

### DrawerClassNames / DrawerStyles

`classNames` / `styles` 的四个 key（类型定义在 `inter.ts`，两侧一致，**均无 `root` key** —— `rootClassName` / `rootStyle` 是独立 props）：

| key     | 目标节点                      | 说明                    |
| ------- | ----------------------------- | ----------------------- |
| mask    | `-{prefix}-mask`              | 遮罩                    |
| wrapper | `-{prefix}-content-wrapper`   | 面板外层容器            |
| section | `-{prefix}-section`           | 面板本体                |
| dragger | `-{prefix}-resizable-dragger` | 拖拽把手（`resizable`） |

`index.ts` 只默认导出 `Drawer` + `export type { DrawerProps }`；`DrawerPopup` / `DrawerPanel` 是内部组件，未导出（与 @v-c 一致）。

## 与 @v-c 差异

| @v-c (vdom)                                                                                                                                             | vapor SFC                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `onClose?: (e: MouseEvent \| KeyboardEvent) => void` prop                                                                                               | `@close` 事件。遮罩点击与 Esc 两条路径都走 emit                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `afterOpenChange` 从 `DrawerPopupProps` 继承，`<Drawer :afterOpenChange="fn">` 合法                                                                     | 字段从 `DrawerPopupProps` 移除，改由 `defineEmits` 暴露（emits 名 `afterOpenChange`），监听写 `@after-open-change`（或 `@afterOpenChange`）。**`<Drawer :afterOpenChange="fn">` 现在 TS 报错**；`:after-open-change="fn"` 在 vapor 下**不报 TS 错、也不报错、回调不触发** —— 该键不在 props 里、编译也不会转成监听器，值被静默丢弃（实测）。事件链：Popup 的 `<Transition @afterEnter/@afterLeave>` → `emit('afterOpenChange')` → Drawer 的 `@after-open-change="internalAfterOpenChange"` 转发 |
| `DrawerProps extends ..., DrawerPanelEvents`：`onMouseEnter` / `onMouseOver` / `onMouseLeave` / `onClick` / `onKeyDown` / `onKeyUp` 是**类型化的 prop** | `DrawerPopupProps` / `DrawerPanelProps` / `DrawerProps` 都不再含这六个 `on*`，改由 `defineEmits` 暴露为 `@mouseenter` 等小写事件。**实测**：`@mouseenter` / `@mouseover` / `@mouseleave` / `@click` / `@keydown` / `@keyup` 全链可用（`<Drawer>` → `<DrawerPopup>` → `<DrawerPanel>` 逐级 `emit` 转发），且不再触发 vdom 下「Invalid prop: type check failed for prop onMouseenter」警告。TSX 里 `onMouseEnter={fn}` 不再有类型（监听要用 `@mouseenter` 形式）                                  |
| `<DrawerPopup {...omit(mp, ['onClose'])} ...>`                                                                                                          | `omit(mergedProps, ['onClose', 'onAfterOpenChange', 'onMouseenter', 'onMouseover', 'onMouseleave', 'onClick', 'onKeydown', 'onKeyup'])`：八个 `on*` 监听器（`onClose` 来自 emits、其余七个来自 attrs 透传）不随 `v-bind` 泼给 Popup，改用事件转发；`afterOpenChange` 单独走 `@after-open-change`                                                                                                                                                                                                |
| `DrawerPopup` `expose({ panelRef })`，Drawer 经 `popupRef.value?.panelRef?.value` 取容器节点                                                            | Popup `defineExpose({ panelRef })`（与 @v-c 一致），`ref="popupRef"` 拿到 expose 代理；vapor 读 expose 会解包 ref，`panelRef` 是**元素本身**，故 Drawer 取 `popupRef.value?.panelRef`（去掉 `.value`，不能像 @v-c 那样再加 `?.panelRef?.value`）。焦点归还实测可用（见下注）                                                                                                                               |
| `{ drawerRender ? drawerRender(content) : content }`：把渲染好的面板 VNode 交给函数、渲染其返回值                                                       | 改为同名 slot：`<slot name="drawerRender">` 以 `<DrawerPanel>` 作默认内容；`drawerRender` 同时从 `DrawerPopupProps` / `DrawerProps` 移除。vapor 没有 VNode、函数返回值无处渲染，留着这个 prop 只会静默无效 —— 不如让 TS 直接报错。代价是丢掉「包一层」的能力：@v-c 可以 `drawerRender(node) => <div>{node}</div>`，slot 只能整体替换面板，无法包裹（机制与 @v-c 不同，见下注）                                                            |
| `<DrawerPopup v-slots={slots}>` 整体透传全部插槽                                                                                                        | 已补 `#drawerRender` 转发（`<template #drawerRender><slot name="drawerRender" /></template>`）；**其余具名插槽仍不转发**，`v-slots={slots}` 的整体透传无法逐个枚举                                                                                                                                                                                                                                                                  |
| `DrawerPanel` 用 `attrsProps = { onMouseenter: props.onMouseEnter, ... }` 把 TSX prop 名小写化后展开                                                    | `@mouseenter="e => emit('mouseenter', e)"` 逐级重发（`DrawerPanel` → `DrawerPopup` → `Drawer`，各自 `defineEmits` 同名事件）；`DrawerPanelProps` 不再含六个 `on*`，事件类型集中在各组件 `defineEmits` 里                                                                                                                                                                                                                            |
| `getContainer?: PortalProps['getContainer']`                                                                                                            | `getContainer?: any`（放宽）                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `DrawerPopup` 收到 `open={mergedOpen.value}`（已 `!!` 归一化的 boolean）                                                                                | 收到 `:open="open"`（原始值）。`mergedOpen` 与 `!!props.open` 恒相等，故仅非 boolean 真值（`open=""`、`open={0}`）的强转语义不同                                                                                                                                                                                                                                                                                                |
| `Placement` 在 `Drawer.tsx` 与 `DrawerPopup.tsx` 各声明一次；`DrawerPopupProps` / `DrawerProps` 定义在各 `.tsx`                                            | `Placement` 只在 `interface.ts` 声明一次；类型集中到 `interface.ts`                                                                                                                                                                                                                                                                                                                                                                                                                             |

> 注：`prefixCls`、`open`、`placement`、`push`、`forceRender`、`autoFocus`、`focusTrap`、`keyboard`、`mask`、`maskClosable`、`destroyOnHidden`、`getContainer`、`panelRef`、`wrapperClassName`、`rootClassName`、`rootStyle`、`zIndex`、`width`、`height`、`size`、`maxSize`、`defaultSize`、`resizable`、`motion`、`maskMotion`、`maskClassName`、`maskStyle`、`id`、`classNames`、`styles`、`drawerRender`、`focusTriggerAfterClose` 全部是非 VueNode 类型，仍走 props。本包**两侧都不存在** `VueNode` / `VNodeChild` 类型的 prop —— 内容一律走默认插槽，没有 Props→Slots 的转换；`motion` / `maskMotion` 是配置对象，`drawerRender` 是函数但返回节点（见上表）。
> `mergedOpen` 同步：@v-c 在渲染函数里 `mergedOpen.value = !!rawProps.open`，本仓用 `watch(() => props.open, ...)` —— 两者都在同一次更新内同步（行为等价），仅实现写法不同，不构成差异。
> 焦点归还要点（已实测）：`focusTriggerAfterClose` 必须进 `withDefaults`（`true`，等价 @v-c 的「不传 = 开启」）—— 否则 vapor 把缺省的可选布尔 prop cast 成 `false`，守卫 `mergedProps.focusTriggerAfterClose !== false` 恒为 false；vapor 读 expose 会解包 ref，取值写 `popupRef.value?.panelRef`（不能再加 `.value`）。关闭后焦点回到触发按钮。
> 事件若以 JSX/TSX 使用，监听以 `onMouseenter` / `onKeydown` / `onClose` / `onAfterOpenChange` 形式传入（作为 props 上的监听器，`@mouseenter` 的等价形式；vapor 的 `emit` 读 `rawValues` / `vnode.props`，两种形式都会命中）；插槽若以 JSX/TSX 使用，以 `v-slots={{ default: () => <Comp /> }}` 形式使用。
> 以下两侧**完全等价**，不构成差异：`inter.ts` 的 `DrawerClassNames` / `DrawerStyles` 四个 key；`context.ts` 逐字一致（`RefContext` / `DrawerContext` 两个 Symbol、四个 hook、`useDrawerContext` 默认值均为 `ref()`）；`mergedSize` 优先级与水平默认 378；`push` / `pull` 推挤链路与默认距离 180、`onBeforeUnmount` pull；`focusTrap` 缺省取 `mask !== false`；`mask` / `maskClosable` / `autoFocus` / `keyboard` / `placement` 的 `!== false` 与 `?? 'right'` 守卫；`useDrag` 的 mouse-only 拖拽与 `[0, maxSize]` 夹取；`resizable` 的三个回调 `onResize` / `onResizeStart` / `onResizeEnd` 均为 `(size: number) => void` 且 Popup 转发 `useDrag` 传入的实参；`useFocusable` 的 `open.value!` 断言与 `flush: 'post'` 自动聚焦；`warnCheck` 的两条 warning；`destroyOnHidden` 的空渲染分支；根节点类名 `-{prefix}-{placement}` / `-open` / `-inline` 与 `clsx` 对象形式；`DrawerPopup` / `DrawerPanel` 的 `inheritAttrs: false`；`DrawerPopup` 的 `defineExpose({ panelRef })` 只暴露 panelRef（不再多暴露 wrapperRef）；attr 分发：`aria-*` 经 `pickAttrs(attrs, { aria: true })` 落 `-section`（Popup → DrawerPanel 逐级透传）、`data-*` 经 `pickAttrs(attrs, { data: true })` 落 `-content-wrapper`、普通 attr 两侧都不落到 DOM（DrawerPanel `inheritAttrs: false` 内部只挑 aria 与 on*）；`setup`+`defaults` → `withDefaults`、`toPropsRefs` → 逐项 `computed`；`defineOptions.name` 仍为 `'Drawer'` / `'DrawerPopup'` / `'DrawerPanel'`；`index.ts` 的导出形态。
